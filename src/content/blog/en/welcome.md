This is the official website of Cutefish, a Linux distribution built around
Cutefish Desktop, a desktop environment with its own compositor, toolkit and
applications.

This blog is where news about Cutefish and Cutefish Desktop is posted. To learn
more about the project and where to find it, see the [About](/about) page; the
source code is on [GitHub](https://github.com/cutefishos).
